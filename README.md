# O Plano DBA — Scripts e Roteiros

Repositório oficial dos scripts e roteiros utilizados nos tutoriais do canal **[O Plano DBA](https://www.youtube.com/@oplanodba)** no YouTube.

Aqui você encontra os comandos prontos para acompanhar cada vídeo.

## Como navegar

```
Tutoriais/
└── Oracle/
    ├── Administracao_Geral/    Tarefas administrativas, scheduler, datapump, etc.
    ├── Backup_Recovery/        RMAN, backup/restore de SPFILE, datafiles, PDBs
    ├── Instalacao/             Instalação, patches, upgrades, preparação do SO
    ├── Multitenant/            CDBs, PDBs, plug/unplug, clone
    ├── Oracle_26ai/            Recursos específicos da versão 26ai
    ├── Performance/            AWR, ADDM, índices, tuning, particionamento
    ├── Seguranca/              Usuários, profiles, privilégios, roles, auditoria
    │   └── Gerenciamento_de_Usuarios/   (playlist)
    └── Tablespaces/            Tablespaces, datafiles, OMF, ASM, quotas
```

## Padrão dos roteiros

Todos os roteiros seguem o mesmo formato com seções delimitadas, comandos prontos para colar, e referência ao laboratório:

- **Lab:** Oracle 19c EE Standalone — CDB1 (HUMAN_RESOURCES, CUSTOMER_ORDERS) e CDB2 (SALES_HISTORY, ORDER_ENTRY, PRODUCT_MEDIA)
- **Formato SQL:** `set lines 200`, `col ... format ...`, alias descritivos, tamanho em GB com separador de milhar e duas casas decimais
